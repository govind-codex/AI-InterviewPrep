## 🌊 About The Project

**AI InterviewPrep** is an intelligent interview preparation platform designed to help candidates prepare specifically for the jobs they are targeting.

Instead of providing generic interview questions, the application analyzes:


Your Resume
     +
Your Profile
     +
Job Description
     ↓
 AI Analysis Engine
     ↓
Personalized Interview Strategy


It then generates customized:

* 🎯 Job-profile match analysis
* 🧠 Technical interview questions
* 💬 Behavioral interview questions
* 📊 Skill-gap analysis
* 🗺️ Preparation roadmap
* 📈 Match score
* ⚡ Targeted preparation strategy

# 🚀 Quick Start

## 1️⃣ Clone the Repository


git clone https://github.com/govind-codex/ai-resume.git

cd YOUR_REPOSITORY


---

## 2️⃣ Backend Setup

Navigate to the backend:


cd Backend


Install dependencies:


npm install

Create a `.env` file:


PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

GEMINI_API_KEY=your_gemini_api_key


Start the development server:


npm run dev

Backend should now be running on:


http://localhost:5000


---

## 3️⃣ Frontend Setup

Open another terminal:


cd Frontend


Install dependencies:


npm install


Start the frontend:


npm run dev

Open:


http://localhost:5173


---

## 🔐 Environment Variables

| Variable         | Description                           |
| ---------------- | ------------------------------------- |
| `PORT`           | Backend server port                   |
| `MONGO_URI`      | MongoDB Atlas connection URI          |
| `JWT_SECRET`     | Secret used for authentication tokens |
| `GEMINI_API_KEY` | API key used for AI analysis          |

> ⚠️ Never commit your `.env` file or API keys to GitHub.

Add this to `.gitignore`:

gitignore
.env
node_modules/
dist/

## 🎯 Project Objective

The goal of **AI InterviewPrep** is simple:

> **Stop preparing for every possible interview question and start preparing specifically for the job you want.**

Traditional interview preparation platforms provide the same questions to everyone.

AI InterviewPrep creates a strategy based on:

```text
YOUR EXPERIENCE × JOB REQUIREMENTS × AI ANALYSIS
```
